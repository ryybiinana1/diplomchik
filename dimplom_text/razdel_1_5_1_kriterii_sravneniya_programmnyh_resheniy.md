# 1.5.1. Критерии сравнения программных решений

Для сопоставления существующих программных решений целесообразно использовать критерии, вытекающие из требований к инструменту, сформулированных в подразделе 1.2.2. Такой подход позволяет сравнивать аналоги не по формальным маркетинговым характеристикам, а по их пригодности к решению конкретной прикладной задачи прогнозирования оттока.

В качестве основных критериев далее рассматриваются: поддержка пользовательских данных, то есть возможность загрузки собственных наборов и сопоставления их структуры с рабочей схемой; контроль качества набора, включающий профилирование данных и выявление проблемных признаков; гибкость моделирования, выражающаяся в настройке горизонта прогноза, параметров выборки и сравнении нескольких алгоритмов; интерпретация результатов, предполагающая представление итогов скоринга в удобной для пользователя форме; учет экономического эффекта и возможность приоритизации клиентов.
